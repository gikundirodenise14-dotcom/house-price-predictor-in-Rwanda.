\# House Price Predictor in Rwanda



\## About the Project



This project is a machine learning project that predicts house prices in Rwanda based on different house features.



The project was developed using Python and Jupyter Notebook. A regression model was trained using house price data and saved for making future predictions.



\## Main Objectives



\* Analyze house price data.

\* Clean and prepare the data.

\* Train a machine learning model.

\* Predict house prices.

\* Create a simple application for prediction.



\## Tools Used



\* Python

\* Jupyter Notebook

\* Pandas

\* NumPy

\* Scikit-learn

\* Matplotlib

\* Streamlit

\* GitHub



\## Project Files



\* `app.py` – application for house price prediction.

\* `Denyse ML.ipynb` – machine learning work and data analysis.

\* `Denyse ML (1).ipynb` – another version of the machine learning notebook.

\* `regression.ipynb` – regression model development.

\* `house\_price\_model.sav` – saved machine learning model.



\## How It Works



The project takes house information, processes the data, and uses the trained machine learning model to predict the estimated house price.
